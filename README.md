## 🎯 What is Multi-Timeframe Scanner?

Multi-Timeframe Scanner is a professional desktop application that analyzes **37 currency pairs** across **3 timeframes simultaneously** (5 seconds, 30 seconds, and 5 minutes) to detect strong trend confirmations for binary options trading.

### ✨ Key Features

- 📊 **Real-time scanning** of 37 pairs (OTC + standard markets)
- 🔄 **Multi-timeframe confirmation** (CALL & PUT signals)
- 💪 **Smart strength algorithm** (0-100% scoring)
- 🎯 **Confidence levels**: VERY HIGH / HIGH / MEDIUM
-  **Real & Demo balance display** with auto-refresh (60s)
- 🔔 **Audio alerts** when signals are detected
- 🌍 **18 languages** with country flags

## 🚀 Installation

1. Go to the **[Releases](https://github.com/MTF-TradingSystem/MultiTimeframeScanner/releases)** page
2. Download the latest `MTF-Scanner-vX.X.X.zip`
3. Extract the ZIP to a folder of your choice
4. Run `MultiTimeframeScanner.exe`

> ⚠️ **Windows SmartScreen Warning:** If Windows shows "Windows protected your PC", click **"More info"** → **"Run anyway"**. This is normal for new software without a paid code signing certificate.

## 📖 How to Use

1. **Launch** the application
2. **Select your language** from the dropdown menu
3. **Enter your IQ Option credentials** (email and password)
4. Click **"⚡ CONNECT TO IQ OPTION"**
5. Wait for the connection and balance loading
6. The scanner will automatically start analyzing all pairs
7. **Trade following signals** with HIGH or VERY HIGH confidence

| Confidence | Meaning | Recommendation |
